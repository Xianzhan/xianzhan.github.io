# 类加载

JVM **动态** *加载(Loading)*、 *链接（Linking）* 和 *初始化（Initialization）* 类和接口。**加载**是指查找具有特定名称的类或接口类型的二进制表示，并基于该二进制表示创建类或接口的过程。**链接**是指获取类或接口并将其组合到 JVM 的运行时状态中以便执行的过程。类或接口的**初始化**包括执行类或接口初始化方法 `<clinit>`。

## 加载

加载的任务是找到 `class` 文件并将其加载到内存中：

1. 根据类的全限定名（如：`java.lang.String`）定位 `class` 文件
2. 读取 `class` 文件的二进制字节流
3. 将字节流转换为元空间的运行时数据结构（`java.lang.Class`）

## 链接

### 验证

验证（Verification）确保被加载的类符合 JVM 规范且不会危害 JVM 安全。验证可能会导致加载其他类和接口，但不一定会导致它们被验证或准备好了。

### 准备

准备（Preparation）阶段包括为类或接口创建 `static` 字段，并将其初始化为默认值。这不会执行任何字节码。

### 解析

解析（Resolution）是从运行时常量池中的符号引用动态确定一个或多个具体值的过程。最初，运行时常量池中的所有符号引用都是未解析的。

## 初始化

类加载过程中的最后一步，真正开始执行类定义中的 Java 代码，即 `<clinit>`。
