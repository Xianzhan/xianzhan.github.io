# 角色权限基础

## 概述

角色权限系统的核心目标是：**对系统内的用户访问进行控制，确保用户只能访问其被授权的资源**。在 Java 的世界中，这通常是通过 **RBAC** 模型来实现。

## RBAC

RBAC(Role-Based Access Control, 基于角色的访问控制)的核心思想是：将权限赋予角色，再将角色赋予用户。用户通过**扮演角色**来间接获得权限。

- 用户：系统的使用者。
- 角色：一组权限的集合，代表一个职位或身份（如：管理员、普通用户、访客）。
- 权限：对系统资源的具体操作许可，通常表示为`资源:操作`（如：`user:add`、`order:query`、`report:export`）。

关系：用户 <-> 角色 <-> 权限。这是一种多对多的关系。
