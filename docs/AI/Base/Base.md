# AI 基础

## 人工智能

人工智能(Artificial Intelligence, AI)是一门让机器表现出**类似人类智能行为**的学科，旨在使机器能够执行诸如推理、学习、规划、决策和语言理解等任务。

实现路径：
1. 人工规则（早期专家系统）
2. 机器学习

## 机器学习

机器学习（Machine Learning, ML）使人工智能的一个子领域，强调通过**数据训练模型**，使其在没有明确编程规则的情况下，学会从数据中识别模式并做出预测或决策。

经典方法：
1. 线性回归
2. SVM
3. 决策树
4. 随机森林
5. 深度学习

## 深度学习

深度学习（Deep Learning, DL）是机器学习的一个子领域，主要关注使用**多层神经网络**（深度神经网络）来从大量数据中**提取特征**和进行复杂任务处理。

代表作：
1. CNN（图像）
2. RNN/Transformer（序列）

## 自然语言处理

自然语言处理（Natural Language Processing, NLP）研究对象是 "人类语言"，让机器能读、写、理解、翻译、对话。

实现：
1. 规则+统计（早期）
2. ML/DL

## 大语言模型

大语言模型（Large Language Model, LLM）是深度学习 + NLP 结合后的当前主流产物。用超大规模参数量的 Transformer 模型，在海量文本上预训练，再做下游 NLP 任务。
